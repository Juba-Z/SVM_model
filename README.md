# 8-Puzzle Solver & AI Projects

A collection of AI and Python projects featuring an 8-Puzzle solver using **A\*** and **Greedy Search** algorithms, a Maze solver, and NLP experiments.

## Projects

| File | Description |
|------|-------------|
| `projectAI_V1.py` | 8-Puzzle with GUI (tkinter) — solved using **A\* Search** |
| `greedy_functional.py` | 8-Puzzle CLI — manual play or auto-solve using **Greedy Search** with Manhattan Distance |
| `Maze Project.ipynb` | Maze solving with various search algorithms |
| `NLP Project/` | Natural Language Processing experiments |
| `sync_prices.py` | Price sync utility (Excel + SQLite) |

## Quick Start

```bash
# GUI version
python projectAI_V1.py

# CLI version
python greedy_functional.py
```

## Algorithms Used

- **A\* Search** — optimal solution with f(n) = g(n) + h(n)
- **Greedy Best-First Search** — fast solution using Manhattan Distance heuristic
